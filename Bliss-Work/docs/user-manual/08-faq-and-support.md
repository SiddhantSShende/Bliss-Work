# 8. FAQs and Support

## Frequently asked questions

### Where do I get the correct BlissWork link?

Use the workspace URL supplied by your organization. The repository's localhost URL is for development. A production login URL was not confirmed.

### I cannot sign in. What should I do?

Check the email and workspace URL, follow the security-check prompt, and use **Forgot password?** if needed. Wait if the application reports too many attempts. See [Getting started](./02-getting-started.md).

### Why can I not invite or manage a teammate?

The invitation screen and member administration controls are role-gated. Ask an organization admin to verify your role and the workspace's policy.

### Why do I not see a task or project?

Confirm the active workspace, task category, people/channel filters, and date/schedule state. A task can appear in different categories after acknowledge, ignore, complete, leave, or miss transitions.

### Can I delete a task?

A general task deletion action was not established in the main user-facing task routes. Task state actions and project completion are documented; availability of any administrative delete function is **[To be confirmed]**.

### Can I restore deleted Mail?

The Mail UI shows a Deleted folder and a **Restore** action; source UI text describes deleted mail as retained for 90 days. Confirm the message is still within the retention period and restore it from the appropriate mailbox view.

### Why is a report empty?

The selected date range may contain no activity or tasks. Widen the range and confirm you selected the intended member/scope. Activity data may also depend on deployment settings.

### Can I connect Slack, Gmail, or Teams?

The backend has integration/OAuth API code, but a corresponding user-facing connection screen was not found in the main navigation. Availability is **[To be confirmed]**; ask your administrator rather than entering credentials into an unverified screen.

### Does WhatsApp forwarding confirm delivery?

No. The UI source indicates a WhatsApp handoff; it does not confirm that the recipient received or read the message.

### Does BlissWork record activity?

The application includes activity and session views. Repository documentation says a user can view their own activity and workspace admins can view others' records. Collection sources and policy depend on configuration; review your organization's privacy notice.

### What languages are supported?

English is the production-ready language in the source localization documentation. Other catalogs exist but are gated pending review. Mobile localization support is not established.

Mobile includes **Settings > Help & Support > Contact**, which opens the device's email app. The target address is not reproduced in this manual until the responsible owner confirms it as an approved public support contact.

When reporting a problem, include the non-sensitive error text, app version if visible, platform, approximate time, affected screen, and steps to reproduce. Never send passwords, MFA/backup codes, session cookies, tokens, or customer/private message data.
