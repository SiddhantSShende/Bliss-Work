# Korean (ko) glossary

Korean (South Korea). Sentences use polite 해요체 (-요) throughout; buttons, menu items, tabs and labels are concise noun/verb-stem forms ("저장", "취소", "새로 만들기"). Plural groups use only `_other` (Korean has one CLDR category). ASCII digits, counters attached to the number with no space ("3개", "5명", "2일"). Postpositions are kept grammatical by restructuring around runtime values ("{{name}}님", "{{name}}에게/에/에서", "라벨: {{value}}") rather than using 은(는)/이(가). The brand "BlissWork" is the only value placed before 가/를/로/와 (it ends in a vowel sound).
