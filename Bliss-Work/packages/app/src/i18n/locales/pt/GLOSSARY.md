# Portuguese (pt-BR) glossary

Brazilian Portuguese, informal-neutral "você". Plural groups use `_one` / `_many` / `_other`
(`_one` covers 0 and 1; `_many` is for 1,000,000+ and carries "de" where required).
Gender-neutral wording preferred ("pessoa", "membro", "participante").
