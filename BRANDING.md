# BlissWork Branding & Logo Guide

This document explains how the BlissWork logo and branding assets are organized and used across the application.

## Centralized Asset Location

All branding assets are centralized in the `/assets/` directory:

```
/assets/
├── logo.png              # Master BlissWork logo (PNG)
├── index.ts              # TypeScript export of asset paths
└── README.md             # Asset documentation
```

## Logo Usage by App

### Web App (`/apps/web/`)

**Favicon (Browser Tab):**
- Uses SVG favicon at `/apps/web/public/favicon.svg`
- This should be updated to match the centralized logo or replaced with the PNG version

**Navbar Logo:**
- Component: `<Wordmark />` (from `@blisswork/ui`)
- Location: `packages/app/src/features/TopNavbar.tsx`
- Renders the SVG Logo + "BlissWork" text

**Background Branding:**
- CSS gradient mesh (`.brand-mesh`) with brand colors
- Location: `apps/web/src/index.css` and `packages/app/src/routes/AppShell.tsx`
- Colors: Blue (#4F6BF6) to Purple (#9A4DF0) gradient

### Desktop App (`/apps/desktop/`)

**Window/Taskbar Icon:**
- File: `apps/desktop/build/icon.png`
- Should be copied from `/assets/logo.png` during build setup
- Used in: Window title bar, taskbar, system menus
- Reference: `apps/desktop/src/main/assets.ts`

**System Tray Icon:**
- Same `icon.png` file, automatically resized to 16×16 by Electron
- Used across Windows, macOS, and Linux

**Microsoft Store (AppX/MSIX):**
- Store tiles generated from icon: `apps/desktop/build/appx/` directory
  - `StoreLogo.png` (50×50)
  - `Square44x44Logo.png` (44×44)
  - `Square150x150Logo.png` (150×150)
  - `Wide310x150Logo.png` (310×150)
  - `LargeTile.png` (310×310)
  - `SmallTile.png` (71×71)
  - `SplashScreen.png` (620×300)
- Generated by: `apps/desktop/build/gen-appx-assets.sh`
- Command: `npm run icon` (in apps/desktop)

## React Logo Components

Available in `@blisswork/ui` package:

### `<Logo />`
SVG logo mark with theme color support. Renders with CSS variables for color theming.

```tsx
import { Logo } from '@blisswork/ui'

<Logo size={32} />  {/* Default 32px */}
<Logo size={64} className="my-custom-class" />
```

### `<Wordmark />`
Logo + text lockup ("BlissWork" with "Work" in accent color).

```tsx
import { Wordmark } from '@blisswork/ui'

<Wordmark size={26} />  {/* Default 28px */}
```

### `<ImageLogo />`
PNG-based logo for static display without theme styling.

```tsx
import { ImageLogo } from '@blisswork/ui'

<ImageLogo size={32} />
```

## Asset Exports

Centralized exports in `/assets/index.ts`:

```typescript
import { ASSETS } from '../assets'

// Use in component:
const logoUrl = ASSETS.logo  // => '/assets/logo.png'
```

## Brand Colors

Primary colors defined in CSS:

```css
--color-brand-from: oklch(0.62 0.19 264);  /* Blue #4F6BF6 */
--color-brand-to: oklch(0.6 0.23 302);     /* Purple #9A4DF0 */
--color-accent: oklch(0.58 0.22 285);      /* Violet */
```

Used in:
- `apps/web/src/index.css`
- `apps/desktop/src/renderer/index.css`
- `packages/ui/src/components/Logo.tsx`

## Updating the Logo

### If You Have a New Logo PNG

1. Save it as `assets/logo.png` (replace the existing file)
2. For desktop app icon usage:
   ```bash
   cp assets/logo.png apps/desktop/build/icon.png
   ```
3. If you have the SVG source, also update `apps/desktop/build/icon.svg`
4. Regenerate Windows Store tiles (if packaging for Store):
   ```bash
   cd apps/desktop
   npm run icon
   ```

### If You Need to Change the SVG Logo

1. Edit `apps/desktop/build/icon.svg`
2. Update `apps/web/public/favicon.svg` to match
3. Regenerate all assets:
   ```bash
   cd apps/desktop
   npm run icon
   ```
4. Copy the main icon to assets:
   ```bash
   cp apps/desktop/build/icon.png assets/logo.png
   ```

## Brand Colors Usage

- **Web/Desktop UI:** CSS variables automatically applied
- **Logo Component:** Uses `--color-brand-from`, `--color-brand-to`, `--color-accent`
- **AppX Manifest:** `backgroundColor` set to `#6D5BF0` (brand midpoint) in `apps/desktop/package.json`
- **Theme System:** Tailwind v4 @theme block defines all tokens

## Summary

- **Single Source of Truth:** `/assets/logo.png`
- **Web Display:** `<Logo />` or `<Wordmark />` components
- **Static Images:** `<ImageLogo />` component
- **Desktop App:** `apps/desktop/build/icon.png` (should mirror `/assets/logo.png`)
- **Icons:** Generated from SVG source via build scripts
- **Colors:** CSS variables + Tailwind theme

All branding should reference this centralized location. Never hardcode logo paths elsewhere.
